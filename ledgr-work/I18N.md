# Ledgr v4 — i18n Implementation

## Architecture

Zero-dependency i18n — pure React context + localStorage.
No next-intl, no server-side routing changes, Vercel-safe.

## File Structure

```
src/
  locales/
    en.ts          ← Master (source of truth) — Translations type exported here
    nl.ts          ← Dutch — satisfies Translations type
    fr.ts          ← French — satisfies Translations type
    de.ts          ← German — satisfies Translations type
  lib/i18n/
    index.ts       ← LOCALES registry, detectLocale(), persistLocale()
    translate.ts   ← TranslationKey type, translate(), interpolate()
    context.tsx    ← I18nProvider, useI18n(), useT() hooks
    banking-keywords.ts  ← normalizeBankingKeyword() NL/EN/FR/DE
  components/i18n/
    LanguageSwitcher.tsx  ← "dropdown" and "inline" variants
```

## Usage

```tsx
// In any client component:
import { useI18n } from "@/lib/i18n/context";

export function MyComponent() {
  const { t, locale, setLocale } = useI18n();
  return <button>{t("common.save")}</button>;
}

// Shorthand (t only):
import { useT } from "@/lib/i18n/context";
const t = useT();

// With interpolation:
t("common.selected", { count: 3 })  // → "3 selected" / "3 geselecteerd" / …
t("import.previewCapped", { total: 308 })  // → "Showing first 50 rows of 308"
```

## Language Detection Priority

1. `localStorage["ledgr-locale"]` — persisted preference
2. `navigator.languages` — browser Accept-Language header
3. Falls back to `"en"` (English)

## Adding a New Language

1. Create `src/locales/XX.ts` — must satisfy `Translations` type from `en.ts`
2. Add to `LOCALES` in `src/lib/i18n/index.ts`
3. Add to `TRANSLATIONS` map in `src/lib/i18n/index.ts`
4. Add date-fns locale import to `src/lib/utils/index.ts`
5. Add banking keywords to `src/lib/i18n/banking-keywords.ts`

## Vercel Compatibility

- No server-side locale routing
- No middleware required
- No cookie headers
- Pure `localStorage` + React `useEffect` — runs only on client
- SSR-safe: starts with `DEFAULT_LOCALE = "en"`, detects after hydration
